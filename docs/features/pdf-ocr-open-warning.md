# PDF 열기 시 OCR 안내

`needs_ocr`는 텍스트 유무 외에 OCR 파이프라인·설정의 오래된 버전도 나타낸다. 자동 안내는 이 값만으로 열지 않는다. `has_text`가 참이고 색인이 정상인 일반 PDF는 기존 OCR·검색 색인을 그대로 사용한다. 색인 복구가 필요한 문서의 자동 안내와 사용자가 직접 선택하는 OCR 재실행·복구는 유지한다.

프레젠테이션 PDF는 기존 정책대로 텍스트 없는 슬라이드만 안내한다. OCR 상태를 아직 확인하지 못했거나 응답 경로가 확인창의 문서와 다르면 텍스트 부재로 표시하지 않고 확인 중으로 표시한다.

회귀 검증은 실제 696페이지 교재의 `has_text=true`, `needs_ocr=true`, 정상 색인·오래된 분석 설정 조합과 이미지 전용 PDF, 일부 슬라이드 누락, 수동 재실행, 색인 복구 및 상태 확인 중 안내를 포함한다.
