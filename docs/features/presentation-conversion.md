# PPT/PPTX 열기와 변환 실패 복구

프레젠테이션은 LibreOffice의 headless 변환으로 생성한 PDF를 사용한다. 각 변환은 짧은 시스템 임시 경로에 별도의 사용자 프로필과 출력 폴더를 사용하며, 이전 변환의 잠금·복구 상태나 다른 문서의 LibreOffice 실행으로 리디렉션되지 않는다. 긴 프로필 경로에서 발생하는 Windows 경로 길이 문제도 피한다. Windows에서는 설치된 soffice.com이 있으면 콘솔 진입점을 사용한다. 정상적인 LibreOffice 사용자 프로필은 변경하지 않는다.

변환 실행은 180초로 제한한다. 출력은 임시 파일로 수집해 자식 프로세스가 파이프를 보유하더라도 대기가 끝나도록 하고, 시간 초과 시 해당 변환의 프로세스 트리를 종료한다. 완료된 PDF만 캐시에 교체하며 작업 폴더는 정리한다. 캐시는 원본의 전체 경로·수정 시각·크기로 구분하고 PDF 헤더를 확인한다.

설치본은 외부 LibreOffice에 PyInstaller의 DLL 검색 경로와 번들 PATH·Python 설정을 전달하지 않는다. 공유 실행 도우미가 프로세스 생성 직전에 시스템 DLL 검색 경로를 복원하고, 생성 직후 백엔드의 경로를 되돌린다. 노트북의 독립 Python 실행도 같은 경계를 사용한다. 변환의 표준 입력은 닫힌 입력으로 명시하고 작업 폴더를 현재 경로로 사용한다.

화면의 PPT 열기 요청 전체는 205초로 제한한다. 현재 변환의 실패를 확인하면 대기를 끝내고 오류를 전달하며, 이전 시도의 실패 상태는 새 재시도를 취소하지 않는다. 변환 오류가 반환되면 추출 텍스트 미리보기에서 오류를 표시한다. 실패·완료·취소 후 진행 알림과 타이머를 정리한다.
