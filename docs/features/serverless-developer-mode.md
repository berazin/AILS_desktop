# 서버 없는 개발 모드

개발판은 현재 AILS 서버 없이 실행한다. 계정 화면에서 이름과 비밀번호에 어떤 값을 입력하든 로컬 로그인하며, 빈 입력은 `개발 사용자`로 로그인한다. 비밀번호는 검증하거나 저장하지 않는다. 로컬 이름은 런타임 데이터 폴더의 `developer-local-account.json`에만 저장하고, 로그아웃하면 삭제한다. 기존 서버 계정 토큰과 크레딧 원장은 변경하지 않는다. 이 기능은 서버 계정 인증을 제공하지 않는다.

설정을 읽거나 교체할 때 기존 AILS 관리형 선택을 ChatGPT 선택으로 전환한다. 명시적으로 선택한 로컬 모델은 유지한다. ChatGPT 모델을 지정하지 않으면 요청 시 계정의 사용 가능 모델 목록에서 첫 번째 모델을 선택한다. ChatGPT는 AI 설정에서 실제 계정 연결을 완료해야 답변할 수 있으며, 연결 오류나 권한 부족을 성공으로 처리하지 않는다. 외부 AI 동의와 로컬 API의 실행별 토큰 검증도 유지한다. ChatGPT 미지원 기능인 PDF 문제 자동 검수는 이 모드에서 사용할 수 없다.

로컬 개발 계정은 학습 메모리의 사용자 구분에 사용할 수 있지만 서버 크레딧, 결제, 관리형 AI 세션을 만들 수 없다. AILS 서버 기능을 다시 시험할 때는 실행 전에 `AILS_DEVELOPMENT_AUTH=server`를 설정한다. 이 임시 정책은 개발판에만 적용한다.

`bootstrap/service_adapter.py`의 서비스 라우팅 인수는 위치 전용이다. HTTP 요청의 `method` 등 같은 이름의 키워드는 호출 대상 서비스에 그대로 전달한다.
