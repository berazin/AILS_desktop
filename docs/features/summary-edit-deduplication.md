# 정리본 검수 수정문의 인접 문단 중복 방어

1차 원문 대조와 2차 개념 검토의 `replace_block` 응답에는 수정 대상 블록만 들어가야 한다. 응답의 첫 문단에 바로 앞의 완전한 소개 문단까지 그대로 복사되면, 앞 문단을 유지하고 수정문에서 복사본만 제거한다. 목록뿐 아니라 일반 문단을 교체할 때도 적용한다.

굵게·기울임·취소선·Markdown 링크와 단순 인라인 강조 태그는 일반 문장의 서식으로 판별한다. 문장 판별에만 서식을 참조하며 중복 비교는 Markdown 원문의 정확한 일치를 사용한다. 링크 주소나 서식이 달라진 문단, 유사 표현, 다른 위치의 반복은 합치지 않는다. 수정문에 새 조건 문장이 앞서 있으면 그 조건을 보존한다.

코드·수식·이미지·제목·인용·표 블록은 이 보정의 대상이 아니다. 앞 블록도 같은 응답에서 수정하거나 수정 위치가 코드 블록 안이면 복사 문단을 제거하지 않는다. 부분 구절 수정과 기존 문서 전체의 재작성·중복 삭제도 수행하지 않는다.

검증은 외부 AI 호출 없이 저장 형식의 검수 응답을 파서와 적용 함수에 통과시킨다. 굵은 Slow Start 문단의 목록·문단 교체, 서식별 정확한 복사, 추가 조건 보존, 앞 블록 동시 수정, 코드·수식 보존, 유사 문구·다른 링크·비인접 반복 보존을 확인한다.
