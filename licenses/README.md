# 라이선스와 고지 자료

이 폴더는 저장소에 있는 서드파티 라이선스와 고지 자료를 찾아볼 수 있도록 모은 곳입니다. AILS 프로젝트 고유 코드에 적용할 별도 라이선스는 현재 저장소에 명시되어 있지 않습니다.

- `manual/`: 수동으로 보관한 의존성 라이선스
- `directml-whisper-commercial/`, `faster-whisper-commercial/`, `ocr-runtimes-commercial/`: 관련 런타임의 라이선스와 배포 고지
- `component-policy.json`: 배포 구성요소의 라이선스 및 검토 정책
- `collected/`: 저장소의 다른 위치에 있는 라이선스·고지 파일의 복사본. 하위 경로는 원본 경로를 그대로 따릅니다.
- [collected/manifest.json](collected/manifest.json): 복사 대상, 원본 위치와 SHA-256

`collected/`는 저장소에 추적된 원문을 복사한 스냅샷입니다. 원본은 빌드·패키징과 출처 확인에 사용될 수 있으므로 기존 위치에도 유지합니다. 의존성을 추가하거나 변경하면 원본과 복사본을 함께 확인해야 합니다.

이 폴더는 설치되는 모든 Python·npm 패키지, 다운로드 모델 또는 최종 배포물의 라이선스 목록을 완전히 증명하지 않습니다. 배포 전에는 실제 포함된 구성요소와 버전을 기준으로 고지·재배포 조건을 별도 확인해야 합니다.
