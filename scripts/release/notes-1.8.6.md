# AILS Developer 1.8.6

- 이미 OCR 텍스트와 정상 색인이 있는 PDF를 열 때 오래된 OCR 설정 때문에 “텍스트가 없다”고 잘못 안내하던 문제를 수정했습니다. 상태 확인 중·기존 텍스트·일부 빈 슬라이드도 구분해 안내합니다.
- 설치본에서 LibreOffice가 백엔드의 네이티브 DLL·Python 경로를 상속하지 않도록 외부 프로그램 실행 환경을 분리합니다.
- 정리본 검수에서 굵게·기울임·취소선·링크가 포함된 소개 문단이 중복 복사되는 문제를 수정했습니다. 원문 대조와 개념 검토 양쪽에 적용하며 새 조건과 코드·수식은 보존합니다.
- PPT/PPTX 변환마다 독립된 LibreOffice 프로필·출력 폴더를 사용합니다. 변환 시간 초과 시 프로세스를 정리하고, 화면의 무한 로딩을 종료해 오류를 표시합니다.
- Windows 백엔드의 NumPy 초기화를 요청 스레드보다 먼저 수행해 첫 문서 검색 시 응답이 멈추는 문제를 방지합니다. 직접 연 외부 문서도 학습 챗봇에서 검색할 수 있습니다.
- 설치·삭제 시 남아 있는 AILS 백엔드를 정리하고 잠긴 파일 때문에 일부 구버전 구성요소만 남는 상황을 방지합니다. 사용자 설정과 작업 데이터는 보존합니다.
- 기존 FFmpeg/FFprobe 재사용, 업데이트 상태 파일 잠금 복구, 서버 없는 개발판 로그인과 ChatGPT 연결을 유지합니다.

Windows x64 개발판입니다. 실제 AI 답변에는 ChatGPT 연결이 필요합니다.
